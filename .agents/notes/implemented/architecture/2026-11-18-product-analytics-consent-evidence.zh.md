# Agent Note: 产品分析的同意凭据

Status: implemented

[English](2026-11-18-product-analytics-consent-evidence.md) | 中文

## 问题

异步账户查询或偏好刷新可能在用户操作之后才完成。该间隙中的授权或账户变更不能为先前的操作提供授权，而设备时钟无法确定跨客户端同意的先后顺序。

## 决策

Host 将可选的产品测量与编辑器内容分开，并默认关闭收集。它在登录或根轮次开始前捕获服务器签发的顺序引用，保留当时的主体和修订号，并随不可变的排队事件发送签名引用。后端在同意事务中将签名顺序与当前决定比较。功能控件在调用操作前捕获主体、修订号和签名引用。撤回会丢弃受影响授权的待处理事件。

签名引用证明后端签发过该顺序，但不能证明设备操作的发生时间。该边界仍由客户端负责。[收集器包](../../../../packages/host/verboo-analytics/README.zh.md)负责 Host 契约。

产品收集器使用独立于账户上下文的安装密钥派生目标端假名。账户身份验证仍用于账户范围的授权和队列隔离，但产品目标不会收到账户 ID 或身份关联请求。消息观察在命令裁决前捕获操作方式、模型选择和授权；只有输入作为普通消息继续处理时才发送观察结果。选择观察仅在 Host 接受选择后发送。

## 考虑过的替代方案

**比较实际时钟。** 设备和后端实例的时钟可能不同，同意事务也可能在时间戳生成之后才提交。

**完成后查询同意。** 后来的授权或账户切换可能为先前操作提供授权或改变其归属。

## 后果

没有先前有效引用的操作不会被测量，包括启动后立即发生或离线时发生的部分操作。接收器需要配置证明密钥并协调后端部署；轮换时必须保留对队列中证明的验证。收集器不会将提示词、响应、工具参数或证明本身放入 PostHog 属性。

不同安装数量只能近似代表人数：一个人使用多个安装时可能被重复计数。只有受支持的 Verboo、OpenAI 账户及官方 DeepSeek 模型目录包含模型维度；自定义提供方和模型名称归为 `other`。未明确指定的推理等级标为 `default`，无法据此确定提供方实际采用的值。渲染端到 Host 的 RPC 在进入持久队列前失败时仍可能丢失观察结果。
