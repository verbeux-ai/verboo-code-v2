# Agent Note: Desktop 用量分析

Status: implemented

[English](2026-11-26-desktop-usage-analytics.md) | 中文

## 问题

Desktop 用户需要在工作区内查看选定的订阅用量指标以及网页仪表板的活动日历。

## 决策

侧栏中的产品页面读取现有的认证用量汇总、各方案汇总、年度活动及耐力服务。它还从网页仪表板的认证实时服务读取账号生成速度，标记估算值和先前测量，并停止显示过期数据。Host 校验所选时间段、分组身份和响应字段；凭据保留在 Host 中，账号变化使待处理响应失效。页面默认显示 30 天，并提供网页订阅面板的其他时间段。页面呈现输入、输出和缓存 token、请求数、方案总量、时间图表和 365 天日历。活动读取失败不会显示为一整年零用量；方案读取失败不会隐藏成功的总量。账号或时间段变化时取消请求。

## 考虑过的替代方案

**嵌入网页仪表板。** 其认证方式和完整指标集合不符合所请求的 Desktop 范围。复用服务器数据与计算方式，让选定体验留在应用中。

## 后果

页面只显示订阅用量，不公开并发、全局排名或等效成本。日历使用本地日历日期并展示服务器每日计数。Host 不向客户端提供私有 API 凭据。
