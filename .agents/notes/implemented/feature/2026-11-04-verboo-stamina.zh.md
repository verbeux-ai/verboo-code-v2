# Agent Note: Verboo 耐力展示

Status: implemented

[English](2026-11-04-verboo-stamina.md) | 中文

## 问题

选定的无限订阅用户需要紧凑的耐力读数，不应看到内部预算或推理速率。账号切换时旧 HTTP 读取可能仍未完成。

## 决策

产品 API 读取经过身份验证的服务器公开耐力数据。网关负责启用范围、用量和限速。Client 不添加准入策略，也不展示金额储备。

聊天输入框使用已注册的资源。资源地址包含当前凭据版本和个人资料 ID；账号替换会取消旧读取并拒绝迟到响应。可见且在线的使用方一次只驱动一个有时限的读取。失败会保留上次确认的数据并将液体标记为过期，服务器返回空列表则隐藏耐力。缺少端点时同样返回空列表，以兼容旧部署。

耐力以液体填充主要发送／停止按钮，外围为细紫色圆环，并保留动作、禁用状态与键盘焦点。输入框已确认的模型通过路由标识与分组 ID 选择服务器分组；元数据缺失或冲突时读数保持未知。耐力仅在聊天中显示。减少动态效果的偏好会停止波浪，装饰对辅助技术隐藏。

## 考虑过的替代方案

**从实际 TPS 推断上限。** 提供方容量和传输延迟会独立于服务器预算影响实际速度，因此该读数无法确定准入上限。

**由每个组件独立轮询。** 独立缓存可能不一致，并保留不同账号版本的数据。现有资源注册表提供共享数据，并在最后一个使用方离开时释放提供方。

## 影响

耐力不进入提示词、Session 持久化或本地凭据。离线窗口显示保留的读数，而不会虚构恢复。此功能仍要求后端试点选定相应账号和订阅。

所属 API、资源生命周期和组件测试覆盖无效响应、失败、账号变化重放、取消和按钮装饰。构建后的浏览器验收使用本地 API 覆盖聊天以及其他页面不显示耐力的行为。
