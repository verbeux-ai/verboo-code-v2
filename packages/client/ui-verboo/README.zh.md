# @deepseek-ai/dsh-client-ui-verboo

[English](README.md) | 中文

<a id="summary"></a>
## 概述

使用 Verboo Code 的引导、项目导航、连接和订阅页面。中性配色、少量 Verboo 点缀、官方图标与 Lucide 图标替换均由此包管理。连接失败时显示吉祥物并保留重试操作。桌面桥接报告更新时，侧边栏显示圆形下载指示器，并在可能有工作运行时确认中断。

ChatGPT 登录和用量功能需要注入 `remote.openaiAccountLogin` 与 `remote.llmOpenaiAccount` 服务。登录成功后，界面会收到返回的账户状态。用量读数使用 Client Remote 装配重新导出的订阅路由类型；此包不另行声明订阅命名空间。

## 使用此包

方案或连接读取失败时保留先前数据，并提示数据可能过期及提供重试；账号退出时还提供重新登录。更新失败时，侧边栏气泡提供重试操作。

`verboo` 配置会加载此插件。`refreshIntervalMs` 控制可见窗口中账户和试用状态的刷新间隔（5000ms）；`staminaRefreshIntervalMs` 控制耐力读取间隔（2000ms）；`handoffTimeoutMs` 限制授权和结账核对时间（180000ms）。[Config](src/config.ts) 校验这些设置。 在偏好设置中启用“耐力（调试）”，或设置 Host 的 `staminaDebug`（默认 `false`）可查看服务器的精确耐力百分比、方案名称、读取时间，并手动刷新。诊断与水位指示器共用资源，不在本地估算消耗，也不显示推理速度。 开关通过共享配置表单持久化；保存被拒绝时显示错误，不宣称成功。

服务器选定的账号在发送／停止按钮内看到液体耐力，外围有一圈细紫色圆环。液体与诊断跟随编辑器已确认的模型选择，通过订阅或目录中的路由标识匹配服务器分组 ID，不使用其他订阅的百分比兜底。分组元数据缺失或冲突时读数保持未知；所选分组没有耐力数据时，诊断显示其名称。装饰保留原箭头、动作、禁用状态和键盘焦点。减少动态效果的偏好会停止波浪。按账号寻址的资源在窗口隐藏或离线时暂停读取，失败后保留上次确认的数据，并在账号变化时丢弃旧响应。编辑器与耐力诊断不显示生成速度或速率上限。耐力指示器不公开服务器预算或定价数据。分析页面还按方案显示耐力。

对话行紧凑且保持单行，菜单使用独立的列，长标题会截断。仅当该对话正在处理时，标题左侧才显示小型旋转指示器；非活动对话不显示状态文字，也不预留指示器空间。输入框通过现有的 Session 和连接服务显示等待用户操作、启动、重连和失败反馈，空闲时不占用空间。连接页面将已拥有的账号、用户自己的 MCP 服务器与目录分开呈现。MCP 服务器属于本页自身的清单，因此紧随账号列表，不再单独显示标题：页面标题在刷新旁提供唯一的“添加 MCP 服务器”操作，而“已启用的 MCP 服务器”计数会滚动到同一列表。目录初始为收起状态：每个类别显示一张卡片及其服务数量，选择类别后只显示该类别的服务，每次四十项。搜索会跨所有类别查找而无需先选择类别，单击即可返回类别列表。服务卡片和已拥有的账号在名称旁显示目录中的品牌标识；目录未提供或标识加载失败时改用产品自带的字形。公共服务无需登录即可使用。MCP 服务器在一个对话框中定义——名称、传输方式、端点或命令，以及其请求头或环境变量键——保存前先校验，也可在保存前直接测试。远程 MCP 服务器可选择身份验证方式：静态请求头，或 OAuth——一个“登录”操作即可打开浏览器，由 Host 保存生成的令牌。浏览器流程无法访问的服务器可改为粘贴令牌，而“退出登录”会丢弃授权。机密值只提交一次，由 Host 保存且不再显示；编辑服务器时只列出键名，值留空。启用、测试与移除只需一次点击或一次确认，移除会一并撤回已保存的机密。

分析页面提供账号实时生成速度、365 天活动日历、按方案的服务器耐力、输入及输出 token、缓存 token、请求数、周期图表和有效方案用量。数据来自订阅用量，默认显示 30 天，失败时明确提示。

方案卡片展示服务器提供的价格、完整说明与每个方案的一项操作，便于比较。仅当目录包含两种计费周期时才显示周期标签。已取消或过期的订阅默认折叠，付款问题始终可见。目录价格未知时会打开网站，不会暗示免费。购买与管理仍使用经过身份验证的浏览器流程。

对话从一个窗格开始。新建对话页面和对话中均可使用侧栏切换按钮，将其收起为 56px 的图标栏，或再次展开；收起过程是滑动加交叉淡出——内容保持冻结的展开宽度在原位淡出，由框架列滑动裁切，栏布局仅在淡出结束后应用，因此滑动过程中没有任何行重排。减少动态效果偏好会同时停用这两个过渡。项目对话列表展开和收起时有短暂过渡；减少动态效果时停用，收起的内容不可交互。搜索会先展开已收起的图标栏，再获取焦点。macOS 使用 Command+D 向右拆分，增加 Shift 向下拆分，Option+Command+方向键切换焦点；Windows 使用 Control+D、Control+Shift+D 和 Alt+Control+方向键。最多四个窗格各自保留 Session 引用，复用共享的对话正文、输入框和操作。Escape 停止所选窗格正在生成的回复；输入框内的上、下方向键浏览该对话已发送的消息并恢复当前草稿。窗格标题和下拉箭头组成可见的控件，点击可打开紧凑的对话搜索器。拆分窗格的标题栏使用独立的中性色背景；搜索器继承当前项目；切换项目同时筛选最近对话并决定新建对话的归属。搜索框自动聚焦，方向键移动、Enter 打开结果。已打开的对话带有标记，筛选结果不重复项目名；选择已经显示的对话会聚焦其窗格。关闭窗格只释放视图，不停止或删除对话。分隔线支持拖动及方向键，最小尺寸由 `minimumPaneWidth` 和 `minimumPaneHeight` 配置。Host 的 volatile `paneLayout` 设置跨应用重启保存对话、焦点和比例，不重载产品插件。窗口缩小时保留布局并允许在工作区滚动；全局页面隐藏但不卸载对话。拆分窗格使用 1.5px 紫色间隔、8px 拖动区域，焦点仅通过共享分隔线和输入框强调，不再给窗格绘制紫色轮廓；未选中窗格的标题栏控件在鼠标悬停或键盘聚焦时显示，触摸设备始终可见；输入框控件在每个窗格中都始终可见。窗格操作的提示显示当前系统的快捷键，偏好设置中可查看窗格快捷键。标题栏控件收起或展开时保持相同行高，包括后台任务标签。内联对话选项是普通操作而非弹出菜单，因此空白窗格不会阻止拆分或导航快捷键。macOS 的 Command+W 与 Windows 的 Control+W 关闭当前视图，最后一个视图关闭后保留空白选择器。输入框始终展开：草稿为空、运行中以及通过快捷键切换窗格焦点时都保留完整的控件行，只有草稿自身的高度增长。选中窗格的输入框显示1px实心紫色描边，即使焦点位于历史记录中；描边与聚焦光环在窗格焦点切换时淡入淡出，不再瞬间跳变，并遵循减少动态效果偏好。首次点击非活动窗格的输入区仅选中窗格；再次点击选中输入区或开始输入文字才进入编辑。已有草稿与附件仍保持展开。偏好设置中的全局 `minimalist` 配置由 Host 保存，对现有与新建窗格统一隐藏助手头像，用户消息保留右对齐的低调中性气泡，助手回复在左侧显示为纯文本。切换外观保留编辑器、历史与运行中的 agent（智能体）。

产品沿用 Verboo Code 网页应用的视觉：深色使用接近黑色的中性配色，搭配 `verboo:code` 字标、本地 Nunito 字体、前景清晰的中性消息气泡和少量控件点缀。Assistant 标志通过 Chat Slot 提供；输入框焦点和气泡前景色使用可选主题令牌。这些资源不包含服务或账号凭证。

试用提醒使用服务器商业状态：到期前24小时内或令牌余额降至20%时，在输入框附近显示提醒及服务器报告的余额。试用实际结束后，应用打开可关闭的 Pro 报价窗口，同时展示其他套餐及说明。关闭仅在当前应用窗口内有效；重新启动应用后再次显示。提醒跟随当前聚焦输入框对应的服务器分组，不将其他分组的试用结束状态套用于已有个人订阅或团队访问权限。

套餐目录以 USD 展示，并要求明确授权付款。已保存银行卡仅显示卡组织及末四位。选择 Pix 后获取独立且有时限的 BRL 报价，确认前显示续费金额和银行授权上限。浏览器负责银行卡设置、收款及额外身份验证；从浏览器返回不代表获得访问权限。重启后的恢复保留原账号及付款尝试。客户端发布前须部署后端试用状态、银行卡摘要和 migration0386；Pix 另要求后端对巴西主账号启用相应能力，并存在有效官方汇率缓存。此提醒不改变模型提示、令牌预算或 KV 缓存。

## 了解实现

<details>
<summary>实现细节</summary>

组件接收渲染器绑定的 hook 与命令。展示模型会丢弃旧账号的响应、合并并发读取、刷新失败时保留有效数据，并在浏览器打开失败时核对已创建的 OAuth 链接。对话框错误由各自的对话框显示。订阅状态来自服务器，浏览器回调不能证明付款。

产品通过 `conversation.hero.intro` 显示简洁的开场问题，通过 `conversation.chat.running.indicator` 显示中性的脉动圆点。其他配置仍可使用共享 Chat 的默认界面。

窄屏下，页面标题与操作纵向排列并在视口内换行。产品侧栏声明自己的底部位置 `verboo.sidebar.foot`，并将其渲染在套餐快捷入口上方；Tauri 更新指示器位于附近，准备完成后可打开气泡。首次账号读取完成前，入口页面只显示品牌和账号检查旋转指示器，因为欢迎文案与登录按钮描述的状态尚未确认。

</details>

## 模型体验

### 产品集成

#### 模型看到什么

`ProductModel` 不通过界面添加模型输入；用户提交仍由对话功能处理。

#### Token 影响

无；界面偏好与账号元数据不会进入提示词。

#### KV Cache 影响

稳定的工具与提示词前缀保持不变；用户提交和工具结果追加到现有会话。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 结账与账号授权会在系统浏览器打开官方网站或托管 OAuth 页面。应用关闭后不会继续轮询。
