## 使用此包

`verboo` 配置会加载此插件。`refreshIntervalMs` 控制可见窗口的刷新间隔（5000ms）；`staminaRefreshIntervalMs` 控制耐力读取间隔（2000ms）；`handoffTimeoutMs` 限制授权和结账核对时间（180000ms）。[Config](src/config.ts) 校验这些设置。 在偏好设置中启用“耐力（调试）”，或设置 Host 的 `staminaDebug`（默认 `false`）可查看服务器的精确耐力百分比、方案名称、读取时间，并手动刷新。诊断与水位指示器共用资源，不在本地估算消耗，也不显示推理速度。 开关通过共享配置表单持久化；保存被拒绝时显示错误，不宣称成功。

服务器选定的账号在发送／停止按钮内看到液体耐力，外围有一圈细紫色圆环。液体与诊断跟随编辑器已确认的模型选择，通过订阅或目录中的路由标识匹配服务器分组 ID，不使用其他订阅的百分比兜底。分组元数据缺失或冲突时读数保持未知；所选分组没有耐力数据时，诊断显示其名称。装饰保留原箭头、动作、禁用状态和键盘焦点。减少动态效果的偏好会停止波浪。按账号寻址的资源在窗口隐藏或离线时暂停读取，失败后保留上次确认的数据，并在账号变化时丢弃旧响应。界面和提示不显示精确的生成速度或速率上限。界面不公开预算或定价数据。 耐力读数仅在聊天中显示，方案、连接与偏好设置页面不展示该读数。

对话行紧凑且保持单行，菜单使用独立的列，长标题会截断。仅当该对话正在处理时，标题左侧才显示小型旋转指示器；非活动对话不显示状态文字，也不预留指示器空间。输入框通过现有的 Session 和连接服务显示等待用户操作、启动、重连和失败反馈，空闲时不占用空间。连接页面将已拥有的账号、用户自己的 MCP 服务器与目录分开呈现。目录初始为收起状态：每个类别显示一张卡片及其服务数量，选择类别后只显示该类别的服务，每次四十项。搜索会跨所有类别查找而无需先选择类别，单击即可返回类别列表。服务卡片和已拥有的账号在名称旁显示目录中的品牌标识；目录未提供或标识加载失败时改用产品自带的字形。公共服务无需登录即可使用。MCP 服务器在一个对话框中定义——名称、传输方式、端点或命令，以及其请求头或环境变量键——保存前先校验，也可在保存前直接测试。机密值只提交一次，由 Host 保存且不再显示；编辑服务器时只列出键名，值留空。启用、测试与移除只需一次点击或一次确认，移除会一并撤回已保存的机密。

方案卡片展示服务器提供的价格、完整说明与每个方案的一项操作，便于比较。仅当目录包含两种计费周期时才显示周期标签。已取消或过期的订阅默认折叠，付款问题始终可见。目录价格未知时会打开网站，不会暗示免费。购买与管理仍使用经过身份验证的浏览器流程。

对话从一个窗格开始，左侧导航默认折叠。悬停在左侧栏时，现有导航以临时覆盖层展开，不改变聊天尺寸；键盘聚焦和搜索操作也能展开。离开时收起，除非导航仍持有焦点或菜单。固定操作复用现有侧栏切换。macOS 使用 Command+D 向右拆分，增加 Shift 向下拆分，Option+Command+方向键切换焦点；Windows 使用 Control+D、Control+Shift+D 和 Alt+Control+方向键。最多四个窗格各自保留 Session 引用，复用共享的对话正文、输入框和操作。Escape 停止所选窗格正在生成的回复；输入框内的上、下方向键浏览该对话已发送的消息并恢复当前草稿。窗格标题和下拉箭头组成可见的控件，点击可打开紧凑的对话搜索器。拆分窗格的标题栏使用独立的中性色背景，紧凑输入框的发送控件居中；搜索器继承当前项目；切换项目同时筛选最近对话并决定新建对话的归属。搜索框自动聚焦，方向键移动、Enter 打开结果。已打开的对话带有标记，筛选结果不重复项目名；选择已经显示的对话会聚焦其窗格。关闭窗格只释放视图，不停止或删除对话。分隔线支持拖动及方向键，最小尺寸由 `minimumPaneWidth` 和 `minimumPaneHeight` 配置。Host 的 volatile `paneLayout` 设置跨应用重启保存对话、焦点和比例，不重载产品插件。窗口缩小时保留布局并允许在工作区滚动；全局页面隐藏但不卸载对话。拆分窗格使用 1.5px 紫色间隔、8px 拖动区域，焦点仅通过共享分隔线和输入框强调，不再给窗格绘制紫色轮廓；次要标题栏与输入框控件在鼠标悬停或键盘聚焦时展开，触摸设备始终显示。所选窗格始终显示标题栏操作；未选中窗格在悬停或键盘聚焦时显示。窗格操作的提示显示当前系统的快捷键，偏好设置中可查看窗格快捷键。标题栏控件收起或展开时保持相同行高，包括后台任务标签。内联对话选项是普通操作而非弹出菜单，因此空白窗格不会阻止拆分或导航快捷键。macOS 的 Command+W 与 Windows 的 Control+W 关闭当前视图，最后一个视图关闭后保留空白选择器。输入框为空且闲置、运行中或通过快捷键切换窗格焦点时保持单行。选中窗格的输入框显示1px实心紫色描边，即使焦点位于历史记录中。首次点击非活动窗格的输入区仅选中窗格；再次点击选中输入区或开始输入文字才进入编辑并展开；离开空输入框后重新收起。已有草稿与附件仍保持展开。偏好设置中的全局 `minimalist` 配置由 Host 保存，对现有与新建窗格统一隐藏助手头像，用户消息保留右对齐的低调中性气泡，助手回复在左侧显示为纯文本。切换外观保留编辑器、历史与运行中的 agent（智能体）。

产品沿用 Verboo Code 网页应用的视觉：深色使用接近黑色的中性配色，搭配 `verboo:code` 字标、本地 Nunito 字体、前景清晰的中性消息气泡和少量控件点缀。Assistant 标志通过 Chat Slot 提供；输入框焦点和气泡前景色使用可选主题令牌。这些资源不包含服务或账号凭证。

<a id="understand-the-implementation"></a>
## 了解实现

<details>
<summary>实现细节</summary>

组件接收渲染器绑定的 hook 与命令。展示模型会丢弃旧账号的响应、合并并发读取、刷新失败时保留有效数据，并在浏览器打开失败时核对已创建的 OAuth 链接。对话框错误由各自的对话框显示。订阅状态来自服务器，浏览器回调不能证明付款。

产品通过 `conversation.hero.intro` 显示简洁的开场问题，通过 `conversation.chat.running.indicator` 显示中性的脉动圆点。其他配置仍可使用共享 Chat 的默认界面。

</details>

<a id="model-experience"></a>
## 模型体验

### 产品集成

#### 模型看到什么

`ProductModel` 不通过界面添加模型输入；用户提交仍由对话功能处理。

#### Token 影响

无；界面偏好与账号元数据不会进入提示词。

#### KV Cache 影响

稳定的工具与提示词前缀保持不变；用户提交和工具结果追加到现有会话。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 结账与账号授权会在系统浏览器打开官方网站或托管 OAuth 页面。应用关闭后不会继续轮询。
